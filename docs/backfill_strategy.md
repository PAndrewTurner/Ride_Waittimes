# Backfill Strategy

## Historical Data Sources

### Wait Times (2015-2021)
- **TouringPlans.com**: Free crowd calendar datasets with posted/actual standby minutes for 14 WDW headliner rides
- Use `scripts/ingest_touringplans.py` to convert CSVs to project schema
- Source: https://touringplans.com/walt-disney-world/crowd-calendar#DataSets

### Weather (2015-present)
- **Open-Meteo Historical Archive API**: Free hourly weather data
- Use `scripts/backfill_weather.py` with `--start-year 2015`
- Constraint: max 1 year per API request, ~15 min total runtime

### Events (2015-2026)
- Generated programmatically by `scripts/seed_events.py`
- Recurring events (festivals, hard-ticket events, races) calculated per year
- One-time events (COVID closures, ride openings, hurricanes) hardcoded

### Calendar Dimensions (2015-2030)
- Generated by `scripts/seed_dimensions.py`
- Includes holidays (US federal), school breaks (FL + Northeast), sunrise/sunset times

## Future Sources (Not Yet Implemented)
- Thrill-Data.com historical CSVs
- TouringPlans subscription data (real-time)
- Google Trends demand signals
- Ticket pricing data
